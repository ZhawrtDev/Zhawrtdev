## Sobre mim

Sou desenvolvedor full-stack, com base sólida no ecossistema JavaScript do
front-end ao backend, da interface ao banco de dados. Construo interfaces com
React e React Native, APIs com Node.js e Express, e uso MySQL, MongoDB e
Firebase para persistência e serviços. Em autenticação, trabalho com JWT e
Bcrypt, com cookies HttpOnly no controle de sessão.

Comecei em 2022 e desde então venho desenvolvendo produtos de ponta a ponta.
Nos últimos anos construí múltiplos SaaS em produção, parte deles em
repositórios privados, com backend ativo rodando em diferentes plataformas. O
trabalho do dia a dia acontece além do que aparece publicamente aqui  o que
está no GitHub é uma amostra, não o todo.

Meu foco atual é arquitetura full-stack e integração entre front-end e backend.
Gosto de produto, de sistema que roda de verdade, e de aprender uma camada nova
a cada projeto. Estou aberto a oportunidades e colaborações.

Contato pelo [LinkedIn](https://www.linkedin.com/in/zhwart/).
